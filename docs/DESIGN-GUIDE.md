# デザインガイド

## 基本形状

全アイコンは `viewBox="0 0 24 24"`、線幅2、`stroke-linecap="round"`、`stroke-linejoin="round"` を共通仕様とします。背景は透明、原則として塗りなしです。文字や色だけに意味を依存させず、輪郭だけで主要な用途が判別できる形状を選定しています。

## カラー版

分類ごとに主色・強調色・補助色を設定しています。成功、失敗、警告、情報、ヘルプなど、一般的な状態色が理解を助けるものは分類色より状態色を優先します。色は意味の補助であり、色が失われてもモノクロ版の形状だけで意味が残ることを前提とします。

色覚やテーマの差を考慮し、選択状態、エラー状態、無効状態はアイコン色だけで示さず、ラベル、輪郭、背景、ツールチップなどと組み合わせてください。

## モノクロ版

描画色は `currentColor`、単体表示時の既定値は `#1F2937` です。インラインSVGなら親要素またはSVG本体のCSS `color` に追従できます。個別ファイルを画像として読み込む実装では、既定色のまま表示される場合があります。

## サイズと余白

推奨サイズは16、20、24、32、48pxです。ボタン内ではアイコン外側に最低4px、可能なら8px以上の操作余白を設けてください。タッチ対象自体は各プラットフォームの推奨値に従い、SVG寸法と操作領域を同一視しないでください。

## 命名

- 安定ID: `UUI-` + 4桁以上の連番（現在は `UUI-0001` ～ `UUI-0503`）
- ファイル名: 小文字kebab-case
- 配置: `<variant>/<category>/<slug>.svg`
- スプライトID: `uui-<slug>`

意味を変更せず形状だけを改善する場合はIDとslugを維持します。意味を変更する場合は新しいIDを割り当てます。

## 改変時の規則

1. `viewBox`、線幅、線端、角の仕様を維持する。
2. カラー版とモノクロ版の描画形状を一致させる。
3. 16px表示で主要な輪郭が識別できるか確認する。
4. `<title>`、`<desc>`、`<metadata>`、カタログを同時に更新する。
5. `geometrySha256` と `SHA256SUMS` を再生成する。
6. `node tools/validate.mjs` を通す。
